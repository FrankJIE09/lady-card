# 今夜开牌 · 15 秒竖屏宣传片

画面取自公开站点的手机端实测截图，依次展示首页选牌、翻牌、三人房间及游玩入口。音乐是基于游戏内小姐牌和弦与旋律写的原创短版，无外部歌曲素材。

- 格式：1080 × 1920，30 fps，H.264/AAC，15 秒。
- 时间轴：0–3 秒开场；3–6 秒三套牌；6–10 秒抽牌；10–13 秒中途加入；13–15 秒游玩链接。
- 图片来源：`source/` 中的三张线上验收截图。渲染脚本为 `render.py`，需要 Python 的 Pillow、NumPy 与 FFmpeg。

先运行 `python render.py --stills` 检查代表帧，再运行 `python render.py` 生成 MP4 和封面。输出文件位于本目录；中间帧和音轨位于 `output/`。
